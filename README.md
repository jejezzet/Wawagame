# 🐾 취준생 치와와

치와와 캐릭터를 직접 꾸미고, 원하는 회사를 골라 자소서부터 면접까지 도전해 취업시키는 웹 게임입니다.

## 실행 방법

설치할 것은 없습니다. `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.
(PC와 모바일 모두 지원, 진행 상황은 단계가 시작될 때마다 브라우저에 자동 저장)

## 게임 흐름

```
이름 입력 → 외형(털색·성별) → 의상(셔츠·자켓·하의)
→ 지원 → 자소서 → 스펙 쌓기 → 서류 전형 → 인적성 → 면접 → 결과
                    └── 스트레스·피곤이 100이 되면 언제든 🛋️ 쉼터로 ──┘
```

| 단계 | 내용 |
| --- | --- |
| 캐릭터 만들기 | 털색(하양/검정/베이지), 성별, 셔츠(여자는 블라우스)·자켓(없음 가능)·하의(치마/바지) 색을 좌우로 넘기며 선택. 원색 9가지 |
| 지원 | 삼성전자, SK하이닉스, 현대자동차, 기아, LG전자, 네이버, 카카오 중 선택하거나 '기타'에 직접 입력. 회사마다 최종 합격선이 다름 |
| 자소서 | 3문항을 직접 작성 (문항당 공백 제외 10자 이상). 분량, 키워드, 회사 이름 언급으로 채점 |
| 스펙 쌓기 | 8주 동안 토익·자격증·인턴·알바·산책·낮잠 중 선택. 랜덤 이벤트 |
| 서류 전형 | 자소서×0.4 + 스펙×0.6 이 50점 이상이면 합격, 미만이면 서류 탈락 엔딩 |
| 인적성 | 2-back 게임(50점) + 마법약 만들기(50점, 문항당 3초, 중간에 규칙이 바뀜) |
| 면접 | 질문에 답 고르기. 짖으면 감점이고, 스트레스가 높으면 나도 모르게 짖을 수 있음 |
| 결과 | 인적성×0.4 + 면접×0.6 이 회사 합격선 이상이면 합격 엔딩 |

## 쉼터

- 스펙 쌓기부터 면접까지 스트레스와 피곤이 올라갑니다.
- 둘 중 하나라도 100이 되면, 지금 하던 문제나 주차가 끝나는 시점에 쉼터로 이동합니다.
- 가만히 있어도 1분에 10씩 회복돼 약 5분이면 돌아갈 수 있습니다. 산책(스트레스 -15)과 낮잠(피곤 -15)으로 더 빨리 회복할 수 있습니다 (각 20초 대기).
- 둘 다 50 이하가 되면 멈췄던 곳부터 이어서 진행합니다.

## 파일 구성

- `index.html`: 페이지 뼈대
- `style.css`: 디자인
- `game.js`: 게임 로직. 색상, 회사 목록, 합격선, 밸런스 수치는 파일 상단 상수에 모여 있음

## 테스트용 옵션

주소 끝에 `?fast=1`을 붙이면 쉼터 회복과 결과 발표 연출이 빨라집니다.
