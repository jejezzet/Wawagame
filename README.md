# 🐾 취준생 치와와

치와와 캐릭터를 데리고 자소서부터 면접까지 6단계를 거쳐 취업시키는 웹 게임입니다.

## 실행 방법

설치할 것은 없습니다. `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.
(PC와 모바일 모두 지원, 진행 상황은 단계마다 브라우저에 자동 저장)

## 게임 흐름

| 단계 | 내용 |
| --- | --- |
| 1. 자기소개서 | 빈칸에 들어갈 말을 골라 자소서 완성. 엉뚱한 답을 고르면 점수는 낮지만 간식력이 오름 |
| 2. 스펙 쌓기 | 8주 동안 토익·자격증·인턴·알바·산책·간식 중 선택. 체력/스트레스/돈 관리, 랜덤 이벤트 |
| 3. 서류 전형 | 자소서×0.4 + 스펙×0.6 = 서류 점수. 점수(또는 간식력)에 따라 지원 가능한 회사가 달라짐 |
| 4. 인적성 검사 | 10초 제한 퀴즈 5문제(60점) + 반응속도 미니게임 5회(40점) |
| 5. 면접 | 질문에 답 고르기. 짖으면 감점이고, 스트레스가 높으면 나도 모르게 짖을 수 있음 |
| 6. 결과 | 서류×0.3 + 인적성×0.3 + 면접×0.4 점수가 회사 합격선을 넘으면 엔딩 |

## 엔딩

- 🏢 멍성전자 (대기업): 서류 70점 이상, 합격선 72
- 🚀 왈왈랩스 (스타트업): 서류 45점 이상, 합격선 58
- 🍖 츄르푸드 (간식회사): 간식력 3 이상, 합격선 45
- 🏭 댕댕물산 (중소기업): 누구나 지원 가능, 합격선 40
- 📮 불합격 엔딩

## 파일 구성

- `index.html`: 페이지 뼈대
- `style.css`: 디자인
- `game.js`: 게임 로직 (단계별 데이터와 밸런스 수치는 파일 상단 상수에 모여 있음)
